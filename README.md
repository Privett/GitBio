# GitBio 🚀

A lightweight, minimal developer portfolio & instant profile viewer powered by the GitHub API.

Originally created as my personal bio page, **GitBio** is built as an open-source tool for everyone. Simply append any GitHub username to the URL to dynamically generate a clean bio card on the fly.

---

## 🔗 Live Demo & Usage

- **Default Profile:** [privett.github.io/GitBio](https://privett.github.io/GitBio/Privett)
- **View Any Profile:** Add any GitHub username to the end of the URL:
  ```text
  [https://privett.github.io/GitBio/YOUR_USERNAME](https://privett.github.io/GitBio/YOUR_USERNAME)
